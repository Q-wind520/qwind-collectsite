# 人物电脑壁纸 20 张 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 新增 20 张横屏 2720×1536 高画质人物壁纸（20 步精修、S1 光照 + Aesthetic Boost LoRA、全 general）入库并通过校验。

**Architecture:** 复用 `generate-rating-balance-40.py` / `ingest-rating-balance-40.py` 结构：新建壁纸专用生成脚本（横图 latent、20 步精修、槽 2 放新 LoRA）→ headless ComfyUI 批量出图到 staging → 入库脚本转 WebP 写条目 → 校验。

**Tech Stack:** Python 3（urllib 调 ComfyUI API）、ComfyUI headless（launcher `172.17.0.1:8191`，生图 `172.17.0.1:8190`）、Node `sharp`、Astro content collections。

**Spec:** `docs/superpowers/specs/2026-11-26-wallpaper-20-design.md`

## Global Constraints

- 底模 `anima-aesthetic-v1.1`（fp8_e4m3fn）；CLIP `qwen_3_06b_base`，VAE `qwen_image_vae`。
- latent **1360×768**（16:9，约 1MP）；2× 放大 RealESRGAN x4 → `ImageScaleBy 0.5` → **2720×1536**。
- KSampler：20 步、CFG 4、euler_ancestral、simple、denoise 1；槽 1 `lora_01=None`（精修无 turbo）。
- 槽 2 风格 LoRA：`S1_Dramatic Lighting Anima_V2.safetensors`（触发 `s1_dram`）或 `anima-highres-aesthetic-boost.safetensors`，强度 0.7~0.9；搭配本地风格 LoRA/画师串。
- 质量词：`safe, masterpiece, best quality, year 2025, newest, highres, detailed background, aesthetic, very aesthetic`。
- 负面：基础负面 + `bad hands, extra fingers, bad anatomy`；`child, loli, shota`（分级安全）。
- 全部 `rating: general`、`tier: refined`、`kind: painting`、`experiment: [lora]`，人物 `adult`。
- slug 前缀 `wp20-01..20`；seed 唯一。
- 执行者不打开图片内容，仅校验文件存在/尺寸/格式；视觉审查由用户完成。
- 不提交、不推送，留用户审查。

## Review Focus

- 横图尺寸错误（用回 832×1216 竖图）→ Task 1 测试断言 node7=1360×768、node14 输出 2720×1536。
- 20 步/CFG4 未生效（沿用模板默认 8 步）→ Task 1 断言显式设置 steps=20/cfg=4。
- 新 LoRA 名写错导致加载失败 → Task 1 冒烟测试 + 任务前 `/prompt` 校验；建单前确认两个 LoRA 文件存在。
- 分级串档（出现未成年词 / 非 general）→ Task 1 断言 `adult` 存在、无 minor 词；入库后 lint 全部 20 条目。
- 缺图导致 `pnpm check` 失败 → Task 3 校验 20 个 WebP + `pnpm check` + `pnpm build`。
