这篇不是严格实验，而是对贴吧原帖观点的整理，以及我自己的使用体感。原帖的核心结论是：**不要把 Anima 当成“一个主模型包打天下”的风格探索模型；先用光辉系探索/固定画风，再给 Anima 炼 LoRA。**

## 原帖在说什么

原帖的观察大致是：

- 固定质量和画风提示词，只改变人物、背景、构图，Anima 的画风会大幅跳变；相比光辉系，风格漂移更明显。
- 画风一致性比角色一致性更重要。光辉系在产生新画风时，产出图的风格更统一，适合拿来炼风格 LoRA，把画风固定下来。
- 用 Anima 自己产图时，画风散布较大，拿这些图去炼风格 LoRA 效果可能比较差。
- 因此原帖不建议用 Anima 探索画风，而是用光辉系探索画风、产参考图，再给 Anima 炼画风 LoRA。
- 这样看，Anima 的独立性偏弱，不能像光辉系那样“一个主模型就完事”。
- Anima 对 LoRA 的需求偏高；如果每个风格都要先做一个 LoRA，成本会很高，也很难百花齐放。

## 为什么这个观点符合我的体感

我自己的体验里，最明显的不是“画风变了”，而是**换画师串时，风格和内容会一起漂移**：

- 同一个角色、同一个场景，只换画师串，笔触、配色、光影会明显变化。
- 有时候不只是画风变，还会连带出现 NSFW 元素或更暴露的构图；需要额外加负面提示词、固定种子，或者用 WD14 / 安全节点兜底。
- 想稳定复现一个画风，通常要固定画师串，甚至上风格 LoRA；只靠一个主模型加几句风格词，很难长期稳住。

这和原帖说的“Anima 画风一致性弱、对 LoRA 需求高”是对得上的。至少在我的使用方式里，Anima 更像一个**风格执行端**：给定明确的画师串/LoRA，它能把风格做得很好；但让它自己探索并稳定一个新画风，成本比光辉系高。

## 我会怎么用

- **探索画风**：优先用光辉系或现成的风格 LoRA 产参考图，不在 Anima 上反复盲试。
- **固定画风**：Anima 侧用画师串 + 风格 LoRA + 固定种子；一次只换一个画师，观察风格和分级是否漂移。
- **安全兜底**：换画师串时不要只看画风，内容分级也要一起检查；WD14 安全节点和负面提示词都留着。
- **不要期待一个 Anima 主模型解决所有风格**：把它当成“执行端”，而不是“风格探索端”，心理预期会合理很多。

## 和严格实验的关系

我之前做过一组 Anima / Illustrious 的画风一致性对照，但那组实验用的是较老的 Illustrious-XL v1.0，和贴吧语境里的当前光辉系不匹配，样本也小，因此不足以验证原帖。那篇已经归档隐藏，等以后真正玩 WAI / 当前光辉系时再重做。

所以这篇只记录**原帖观点 + 个人体感**，不作为严格实验结论。
